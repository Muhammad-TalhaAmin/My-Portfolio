# Portfolio Website

## Overview

My portfolio website is one of my most significant and continuously evolving projects.

It was originally developed as a university project using HTML and CSS to demonstrate my understanding of front-end web development. Rather than treating it as a completed academic assignment, I decided to continue improving it and transform it into a professional portfolio that represents my skills, projects, and learning journey.

Today, it has grown beyond a static website into a full-stack portfolio with an AI-powered chatbot, backend functionality, and plans for deployment.

---

## Why I Built It

Initially, the project was created to fulfill a university requirement.

After completing it, I realized it could become much more than an assignment. I wanted a single platform where recruiters, instructors, and other developers could learn about me, explore my projects, and interact with an AI assistant capable of answering questions about my skills, education, and technical work.

This project also gave me an opportunity to learn technologies that are commonly used in real-world web development.

## Challenges

While developing this project, I encountered several real-world challenges, including:

- Converting a static website into a Flask application.
- Integrating an AI chatbot with the frontend.
- Handling API communication between Flask and the chatbot service.
- Implementing secure contact forms with validation.
- Organizing the chatbot's knowledge base.
- Preparing the application for deployment.

Each challenge helped me improve my debugging, problem-solving, and software engineering skills.
