# About

Tixora is a full-stack AI-powered event ticketing platform developed as a collaborative team project. The platform enables users to discover events, securely purchase tickets, receive verified QR-code tickets, and allows organizers to manage events, monitor analytics, and review suspicious transactions through an integrated dashboard.

My primary contribution to the project was designing and developing the AI-powered Fraud Detection System, one of Tixora's core features. I also designed the official Tixora logo, contributing to the project's visual identity.

---

# My Contributions

## AI Fraud Detection System

I designed and implemented the complete fraud detection pipeline that helps protect both customers and event organizers from fraudulent ticket purchases.

My work included:

- Designing the fraud detection workflow
- Creating the machine learning pipeline
- Feature engineering
- Data preprocessing
- Training multiple machine learning models
- Model evaluation and comparison
- Selecting the production model
- Integrating the trained model into the backend
- Real-time fraud scoring
- Automatic suspicious order detection
- Risk-based order flagging for organizer review

The objective was to detect potentially fraudulent transactions while allowing legitimate users to complete bookings without interruption.

---

## Machine Learning

The fraud detection system was built using:

- Python
- Scikit-learn
- XGBoost
- Pandas
- NumPy

The production model evaluates every ticket purchase and generates a fraud risk score in real time. Orders exceeding the configured threshold are automatically sent for organizer review.

# About Tixora

Tixora provides a complete digital event ticketing experience.

Users can:

- Discover nearby events
- Search and filter events
- Purchase tickets securely
- Receive verified QR-code tickets
- Access purchased tickets instantly

Event organizers can:

- Create and manage events
- Configure ticket tiers
- Track ticket sales
- View booking analytics
- Review AI-flagged orders
- Validate QR tickets during event check-in
