# Data Science

A collection of Jupyter notebooks exploring data science and Python fundamentals through real-world datasets. These projects cover pandas, NumPy, data visualisation, and linear regression.

## Notebooks

### Computation with NumPy and N-Dimensional Arrays
Learn how to use NumPy to work with numerical data, including N-dimensional arrays, images and numerical computation with the SciPy ecosystem.

### Pandas: Salaries by College Major
Clean and explore a dataset of undergraduate majors and their salary outcomes using pandas — inspecting DataFrames, cleaning data, and computing statistics like salary spread to find low-risk, high-paying majors.

### Programming Languages
Analyse Stack Overflow post counts for programming languages over time. Uses SQL-exported `QueryResults.csv` data to explore the popularity and growth of languages like Python, Java, and JavaScript with pandas and matplotlib.

### LEGO Analysis
Dive deep into LEGO datasets from [Rebrickable](https://rebrickable.com/downloads/) to explore the history of the company, find the largest LEGO sets, see which themes have the most sets, and track how sets grew in size and complexity over time.

### Google Trends and Data Visualisation
Investigate whether search popularity relates to real-world data. Compares Google Trends search volume against the price of Bitcoin and Tesla stock, and against the US unemployment rate.

### Seaborn and Linear Regression
Explore whether higher film budgets lead to more box office revenue. Scrapes movie budgets and financial performance data, then uses pandas, matplotlib and Seaborn to visualise the relationship and fit a linear regression model.

### Google Play Store App Analytics
A comprehensive analysis of the Android app market, comparing thousands of apps in the Google Play store. Uses Plotly to explore app categories, genres, installs, pricing and revenue estimates.

## Getting Started

Each notebook is self-contained. Install the required libraries and launch Jupyter to explore:

```bash
pip install pandas numpy matplotlib seaborn plotly scipy pillow
jupyter notebook
```
